# coppyz.github.io

Personal academic website of **Zike Zhou** (周子轲), built with [Jekyll](https://jekyllrb.com/) and based on the [AcademicPages](https://github.com/academicpages/academicpages.github.io) theme.

Live site: [https://coppyz.github.io](https://coppyz.github.io)

## Local development

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open <http://localhost:4000>.

## Project structure

- `_pages/` — top-level pages (About, CV, Publications)
- `_publications/` — one Markdown file per publication
- `_data/navigation.yml` — top navigation links
- `_config.yml` — global site settings (title, author info, social links)
- `images/` — site images and favicons
